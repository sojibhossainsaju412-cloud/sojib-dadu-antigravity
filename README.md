# SOJIB DADU - Antigravity CLI

A community setup guide for trying Google Antigravity CLI
inside Debian on Android using Termux and proot-distro.

## Requirements
- Android and Termux
- Debian via proot-distro
- Internet connection
- Google account

## Start Debian
    proot-distro login debian

## Install Git
    apt update
    apt install -y git curl ca-certificates

## Antigravity CLI
Follow Google's official instructions:
https://antigravity.google/cli/install.sh

Check the CLI:
    agy --version
    agy --help

Run:
    agy
